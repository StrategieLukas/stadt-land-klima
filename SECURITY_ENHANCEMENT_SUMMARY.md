**24 October 2026 · concise implementation summary**

Scope: the security and TypeScript work merged in PR #485 from `0000-security-updates` (the security-enhancement branch), including core-service hotfixes integrated from `main`. Staging rollout fixes are identified separately below. This document summarizes implemented changes; it is not production deployment approval.

## Significant security improvements

| Area                        | Implemented protection                                                                                                                                                                                                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Public data access          | Removed the shared Directus credential from browser configuration. Same-origin Nuxt endpoints use private service identities, explicit fields and checked response contracts. Publication, parent visibility and ownership are enforced before data, files or search results become public. Public-role YAML remains unchanged. |
| Candidate and editor access | Added encrypted HttpOnly sessions, origin/CSRF checks and private preview verification. Editor CMS tokens live in Redis rather than browser localStorage. Candidate writes enforce identity, election ownership, permitted questions and Berlin deadlines. Existing candidate/preview links remain compatible.                  |
| Spam and resource abuse     | Hardened ALTCHA purpose/expiry signatures and single-use replay detection. Added atomic Redis rate limits, concurrency controls, bounded bodies/uploads, PDF execution limits and mail-delivery quotas. CSV exports resist spreadsheet formula injection.                                                                       |
| Browser and proxy security  | Enforced nonce-based Nuxt CSP, safer HTML/SVG handling, reviewed local analytics with integrity checks, restricted CORS and safer referrer/log handling. Removed unnecessary executable-code paths in chart/schema tooling. Edge guards block unused CMS GraphQL/hash utilities and unsafe deep-query/WebSocket requests.       |
| Pinned CMS safeguards       | Added authorization-before-side-effect checks, authenticated manual-flow guards, sensitive-settings restrictions, mail-template traversal/symlink protection, connection-time SSRF controls, safe geometry validation and image-size limits. Vulnerable bundled libraries were replaced and tested against actual vendor code.  |
| Search and integrations     | Reconciled existing search indexes with complete pagination and live publication checks. Restricted external proxy paths, methods, redirects and payloads; upstream credentials stay server-side.                                                                                                                               |
| Deployment and credentials  | Added ordered code-first imports, preparation-only startup, private service-account provisioning, scoped credential-retirement plans and drift/replay checks. Database tooling separates the non-superuser application login from the preserved bootstrap operator.                                                             |
| Regression assurance        | Expanded runtime, authorization, malformed-input, disclosure, editor, browser and infrastructure coverage. CI checks types, lint, formatting, extension builds and actual-image security dispositions; audit reports retain actionable findings.                                                                                |

## Staging rollout follow-up

Live verification additionally fixed service-account email validation and concealed-token recovery, token-drift checks, static JS/CSS throttling, donation-widget hydration markup and legacy absolute button links. Corresponding regressions were added; these follow-up changes remain reviewable separately from the merged PR.

**Operational boundaries:** candidate access tokens and municipality preview links are retained by owner decision. Raw audits still report locally backported versions; no blanket advisory suppression was added. Pinned-image dispositions expire **24 November 2026**. Production cutover, real provider delivery checks and native macOS/Windows acceptance remain separate operator verification tasks.
