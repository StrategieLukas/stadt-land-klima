# Stadt-Land-Klima feature inventory

This is the canonical inventory of implemented application functionality. It covers the Nuxt frontend, server routes, Directus schema and permissions, Directus extensions and flows, integrations, and the end-to-end test suite. The inventory was reviewed on 2026-09-08; dependency/security maintenance was reviewed on 2026-10-19, and Phase 6 page/API migration coverage was reviewed on 2026-10-22.

The test column names the most specific automated flow and step where coverage exists. A status of “Not covered by a dedicated automated test” means that a page may be exercised incidentally while browsing another flow, but there is no targeted regression assertion for the functionality. Manual email checks are called out separately and are not treated as automated coverage.

## Important authorization and configuration findings

- Publishing is currently authorized by the authenticated Directus user’s directus_users.verified value in the score-publishing hook. A verified local-team member can publish even when the municipality’s creator_verified value is false.
- Unpublished municipality previews require the server-side preview token and verified authorization; `creator_verified` alone does not grant anonymous preview access. The users.update hook still propagates the local-team administrator’s verified state to attached municipalities; the legacy syncCreatorVerified flow is inactive.
- Directus preview links are built from FRONTEND_BASE_URL. The registration flow checks both the configured link metadata and that the resulting link uses the configured host.
- Registration repairs or retries the exact local-team administrator role and user-localteam junction, then verifies the result. This prevents an account from being created without a usable role.
- Automated coverage is concentrated around ratings, Wahlcheck, local-team registration, user invitations, and Erfolgsprojekte editorial permissions. Many public pages, visualizations, forms, newsletters, donations, and CMS interfaces still need dedicated regression coverage.
- The legacy browser Directus token (`directusToken`) has been removed from the public runtime config. Anonymous content reads use Nuxt server routes and the private server token; authenticated editorial writes use the personal browser client. The Frontend-Public policy is limited to directus_files/directus_folders read only.
